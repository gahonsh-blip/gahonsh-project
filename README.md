# Gahonsh Project — Liquid Glass UI kit

The original zero-dependency landing page for the Gahonsh ecosystem, built as a
Liquid Glass UI study: layered blurred blobs, `backdrop-filter` panels, a CSS
variable theme with a dark/light switch, and a small `script.js` for the theme
toggle and scroll reveal. Hindi-first copy, no build step, no framework.

## Files

```
index.html    the landing page (hi, data-theme="dark")
style.css     the whole design system: tokens, glass surfaces, layout
script.js     theme toggle, scroll effects
showcase/     component showcase pages
```

## Run

Open `index.html` directly, or serve the folder:

```bash
npx serve .
```

## Status

This is the earlier experiment that led to the current production site at
https://gahonsh-blip.github.io. It is kept as a design reference: the glass
technique, the type pairing (Italiana + DM Sans) and the theme tokens are reused
there. New client work goes to the main site, not here.
